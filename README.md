## 🧩 Problema

Como todos sabem, a reciclagem é um processo essencial para a preservação do meio ambiente, a redução da poluição e a diminuição do desperdício de recursos naturais. Atualmente, em Portugal, ainda há muita gente para a qual a reciclagem nem é uma preocupação. Além disso, muitas pessoas têm dificuldade em identificar corretamente os diferentes tipos de resíduos e o contentor apropriado para cada um.

## 💡 Solução

Para ajudar a combater este problema, decidimos desenvolver a **ReciclAI**, uma webapp simples e acessível que permite às pessoas identificar corretamente onde devem colocar o lixo, a partir de uma fotografia. O utilizador dá upload a uma foto do resíduo e, com a ajuda de um modelo de inteligência artificial, a aplicação diz em que contentor deve ser colocado.

Além desta funcionalidade principal, a ReciclAI também inclui uma aba com curiosidades sobre a reciclagem, onde os utilizadores podem aprender mais sobre o impacto dos seus hábitos e ganhar motivação para reciclar melhor.  
O nosso objetivo é facilitar o processo de separação do lixo e, ao mesmo tempo, aumentar a consciência ambiental da população.

## 🛠️ Tecnologias Utilizadas

- **Vite + React** – Usado para construir o frontend da aplicação  
- **Django** – Framework web em Python utilizada para construir e gerir o backend da aplicação  
- **API REST** – Para permitir a comunicação entre o frontend (React) e o backend (Django)  
- **Modelo TrashNet (Hugging Face)** – Utilizado para classificar os resíduos com base em imagens  
- **Linguagens de Programação** – Python, HTML, CSS e JavaScript
